## What it is about

The site you are looking at: static, bilingual, with a detail page for every project. It pays attention to SEO and accessibility (keyboard navigation, structured data and share previews).

## What I did

- **Design and development** of the whole site, with Astro and Tailwind: static, fast and with no backend.
- **Language routes** with `hreflang` and canonical URLs.
- **Each project is one Markdown file per language:** adding one does not require touching the code.
- **Light and dark theme** and a redirect to the browser's language; videos do not autoplay if the system asks for reduced motion.
- **Automated quality:** Prettier, `astro check` and GitHub Actions on every push.
